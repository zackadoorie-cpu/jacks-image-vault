# Jack's Image Vault Phase 5 (v2.2.4): manual albums and bulk selection

Adds private, hand-picked local album membership alongside Smart Collections. Bulk selection works on currently displayed gallery cards or all current filtered records; selection is capped at 10,000. No original images or videos are downloaded by selection, and no file is moved, renamed or uploaded. Use manual album browsing to remove membership; deleting an album only removes its local definition.

Account safety: stored albums use the verified Drive permission ID plus the configured Sheet ID. In-memory album data and transient selections are cleared on disconnect or account change. Invalid JSON is never silently overwritten; storage failure leaves local state unchanged. Backups contain only album names, opaque Drive IDs and timestamps. Imports require user confirmation, retain existing albums and skip conflicts.

Boundaries: at most 40 albums, 10,000 distinct file IDs per album and 1.8 MB backups. Saved IDs absent from the current index remain listed in album counts, not falsely represented as present media.

Preserved: read-only Drive/Sheet access, separate approvals for renames and Sheet writes, thumbnails, MP4/WebM streaming, Windows encrypted sign-in, updater/rollback, video poster limits, Compare/Quick Peek, search and Smart Collections.

CI gates: Chromium fabricated Google browser workflow, Linux/Go security/fuzz/media tests, Windows native/DPAPI tests, and independent release artifact verification.
