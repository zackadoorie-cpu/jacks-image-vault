# Jack's Image Vault v2.2 Phase 3 — Review Center 2.0

Baseline: published and verified v2.2.1 source.

## Targeted improvements
- **Review Inbox → Review next pending:** a one-click, explicit navigation
  into a fresh, unfiltered Needs Review queue, opening the first pending
  item's existing review dialog. This does not trigger sync or remote writes.
- **Truthful review coverage:** a progress indicator for the currently
  loaded library, separating local review saves from pre-existing source
  visual verification. Pending and deferred statuses count separately.
  A missing EXIF date is not treated as an unreviewed image.
- **Status quick filters:** select Needs attention, Review later or Reviewed
  locally without removing the original queue-status select. The source-
  verified count is information, not an automatic approval button.
- **Start reviewing this selection:** a button in Needs Review opens the
  first eligible item in the current search, folder, type and review filter,
  with a clear zero-match disabled state.
- **Dialog position:** displays item index within the currently filtered
  review queue; when a local save removes an item from the pending view,
  the UI states that it is outside the active selection.
- **Less clutter:** JSON imports and local review backup/restore retain
  their existing IDs and handlers inside an accessible disclosure. Mark
  reviewed explicitly says **locally**, not approved in Google Sheets.

## Invariants
- No change to any Google Drive or Sheet OAuth permissions.
- No Drive rename, deletion, move, or automatic Sheet write.
- No modifications to Manifest or Search Index formulas or approval flow.
- No new private metadata stored remotely.
- Existing local review storage, history/undo, import formats and
  verification evidence remain authoritative and unchanged.
- Video streaming, thumbnail scheduling, preview fallback and all five
  gallery density modes stay untouched.
- All existing navigation destinations and public release files remain
  available.

## CI and release
- Chromium fabricated-media E2E: queue entry, local vs source metrics,
  local draft/approval, status filters, backup disclosure, no Google writes.
- Existing browser playback, virtualization, 320px responsive view, review
  inbox, Sheet approval and rename safeguards.
- Linux/Go security/updater fuzz and Windows DPAPI/WebView2/native smoke.
- Ship only after all three CI suites green; a separate release build
  re-verifies and produces checksummed ZIP, EXE and desktop bundle.
