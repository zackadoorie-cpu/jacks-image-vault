# Jack's Image Vault v2.2 — Phase 1 UI Makeover (unreleased candidate)

Baseline: published v2.1.49 source tree, including the corrected PR #109 revert.
This phase changes only HTML, CSS, browser navigation visibility, and synthetic UI tests.

## Changes

- Navigation preserves all 17 existing page destinations and the same three primary groups.
  Review Center keeps four common links visible when expanded. Rename Desk,
  Sheet Approvals and Activity & Undo remain inside a keyboard-accessible
  Advanced & history disclosure.
- All sidebar navigation and Home shortcut icons use a local SVG sprite with
  uniform strokes. No external assets, fonts, or private media are bundled.
- The sidebar footer consolidates settings/update controls under App & account;
  original IDs and handlers stay intact, including compact flyout mode.
- READ-ONLY BY DEFAULT distinguishes browsing from separately authorized,
  per-operation Drive renames and Sheet updates.
- Home presents core metrics and shortcuts, with Vault Pulse and Command Center
  retained behind Detailed library health & sync tools. Their data and
  actions are still computed as before.
- Gallery retains Search, type, sort, grid/list and five-stage density slider.
  The collection picker, tips, and saved searches live under Collections &
  saved searches. Invalid search syntax reveals its feedback automatically.
- Thumbnail queueing, virtualization, video streaming, encrypted sign-in,
  Drive/Sheet workflows, and updater logic are unchanged.

## Safety and compatibility

- No changes to OAuth scopes, Drive metadata, Sheet source cells or formulas,
  rename/undo guarantees, streaming endpoints, or native Windows processes.
- No automatic Drive or Sheet writes. No personal files or tokens in fixtures.
- All original button IDs are retained for event dispatch and accessibility.
- All drawer and navigation actions remain keyboard and mouse accessible.

## Test gates

1. Chromium E2E fabricated Drive and Sheet fixture: 17 destinations,
   access wording, dialogs, toolbar, density control and zero Google writes.
2. Existing browser playback, security, 10k-item virtualization, and 320px
   responsive viewport regressions.
3. Linux/Go, ZIP/updater, OAuth replay and stress tests.
4. Windows EXE, DPAPI, WebView2 and launcher smoke.
5. Separate release only after verified merge and explicit approval.

Future phases (not implemented here) include guided review workflows,
Quick Peek, Compare Mode, local albums and bulk selection.
