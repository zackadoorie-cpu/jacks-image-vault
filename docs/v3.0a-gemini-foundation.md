# v3.0A Gemini foundation

Optional Windows-native AI Studio under App & account. Install the new EXE, save a dedicated Gemini key and select a model. DPAPI encrypts the key in a separate file; existing OAuth is unchanged. Key is never returned to the UI, included in URLs, logs, or usage history. Explicit user confirmation precedes a text or local image test. Local images are resized and re-encoded; no Drive or Sheets reads/writes in this phase.

Standard list prices checked 2026-11-28: 3.1 Flash-Lite $0.25/$1.50 per million input/output, 3.5 Flash-Lite $0.30/$2.50. https://ai.google.dev/gemini-api/docs/pricing . UTC monthly $8 fixed app-side estimated budget; not a Google billing cap. countTokens preflight, persistent conservative reservation before inference, reported usage settlement, unknown charges retain reservation. No automatic retries, tools, grounding or batch. Pricing drift, other clients and external billing not tracked. Usage history is local and separate from key; forgetting key doesn't reset usage. Windows-only DPAPI; no plaintext fallback. CI tests use fake keys and mocked responses, never actual Google credits.
