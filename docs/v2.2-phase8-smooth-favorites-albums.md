# v2.2.8 — Phase 8: Smooth Favorites and Large Manual Albums

This is a focused, read-only gallery polish pass. No new controls or
navigation panels are introduced. The retired Jump Navigator remains absent.

- **Instant favorite action.** In All media, Memes, Photos, Review,
  Memory Lane results, and Manual Album results without a search query, a
  favorite updates the existing heart button in place instead of rebuilding
  every media tile, dropping keyboard focus, or re-queuing visible previews.
- **Correct reactive views.** Favorites, Smart Collections and searched
  galleries still recalculate their filtered results. The keyboard focus
  moves to a replacement favorite button if that media remains visible,
  otherwise to the existing results landmark. Full-details actions retain a
  valid return-focus target.
- **Large Manual Albums.** Gallery filtering creates a temporary Set from
  active album membership once per render. This avoids N × M array scans
  when thousands of Drive entries and album members coexist. No persistent
  index or album storage schema change is introduced.
- **Strict boundaries.** Account-scoped local favorites and albums only;
  no Drive or Sheet writes, new OAuth scopes, autoplay, original media
  downloads, backend modification, or auto-renaming.

Browser tests cover in-place favorite DOM identity and keyboard focus,
Favorites view removal, favorite:true search filtering, zero remote writes,
and a synthetic 10,000-media gallery with 5,000 album IDs whose
`includes` function deliberately throws. Existing Windows sign-in,
large-video playback, gallery virtualization, updater security and recovery
checks remain merge and release gates.

## Urgent compact gallery layout repair

A screenshot of a 1,160-result Meme gallery at Micro density exposed
clipped Compare buttons and neighboring actions. This was a CSS regression
from adding Compare text after the density-specific rules. The repair uses
icon-only Compare buttons in Compact/Ultra Compact/Micro while preserving
accessible aria-labels; the More and Favorite buttons are sized to fit
inside a 70-pixel tile. A bulk selection checkbox is positioned at the
image’s top-right instead of increasing footer width. The full-size and
list-view interfaces remain unchanged. Browser regression tests inspect the
actual bounding rectangles of each existing action on desktop, 375-pixel
and 320-pixel screens, with and without album selection. No new feature or
remote file modification is required.
