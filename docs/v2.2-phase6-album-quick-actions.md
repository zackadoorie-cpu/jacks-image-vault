# Phase 6: Manual Album Quick Actions (v2.2.5)

Start from published v2.2.4. Add album renaming that preserves IDs, members and creation timestamps, with unique-name validation and collision-safe creation. Add existing-account local-only individual Add / Remove controls to Quick Peek and full media details, and a gallery Manage Albums link without another sidebar entry. When a file is removed from an album while it is being viewed, keep the viewer stable until it closes, then refresh filtered membership.

Controls remain hidden for disconnected and sample data, and when no manual album exists. The local 40-album, 10,000-file, 1.8 MB schema validation and non-overwrite safeguards are retained. Single-file changes are atomic and require an explicit click.

Test with synthetic Chromium Drive/Sheet fixture for rename, add/remove from Quick Peek and media details, media viewer stability, no playback, no remote writes and zero exceptions. Require Linux Go/security/stress/fuzz, Windows DPAPI/host/updater, and Chromium checks green before merging, plus independent release workflow verification before publishing.
