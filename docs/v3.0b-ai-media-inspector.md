# Phase 3.0B — AI media inspector (first slice)

Depends on Phase 3.0A. Select an exact still image from the current Drive catalog using a filename/folder filter, then approve a paid analysis. Existing Google read-only authorization downloads only that file (20 MiB limit). Compare metadata and version before and after the download and again after inference; discard results on account/selection drift. Resize to 1024px and strip source metadata before transmission. No Google OAuth token, file name, Drive ID or source folder is sent to Gemini. The provider returns validated structured filename stem, description, tags and category; local decoding supplies dimensions, MIME/size come from verified Drive metadata. Output is preview only, not human verified. No Drive or Sheet writes. No bulk jobs, automatic sorting or persistent proposals yet. Phase 3.0C will add guarded approval and writeback using existing catalog safeguards. Actual API compatibility and user account must be tested after installing the new EXE.
