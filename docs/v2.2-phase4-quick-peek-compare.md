# Jack's Image Vault v2.2 Phase 4 — Quick Peek and Compare Mode (unreleased)

Baseline: verified v2.2.2 from GitHub main.

## User experience
- **Space on a focused gallery preview** opens a lightweight Quick Peek.
  Left/right move through the same filtered result set. Escape closes and
  restores focus. A separate Open full details button invokes the existing
  secure media viewer, including its video playback and personal review.
- **Compare** on each gallery tile adds or removes a temporary selection.
  Exactly two items may be chosen. The contextual bar opens a responsive
  side-by-side comparison, displays file names, folders, descriptions, and
  existing cached previews. Videos are represented by posters only; PDF
  documents have explicit placeholders. Each pane may open full details.
- The compare selection remains while browsing, but is cleared on explicit
  account disconnect. If the library changes, stale identifiers are pruned.
  No comparison selection is written to local or remote storage.
- The comparison overlay never enqueues media downloads or autoplay.
  Quick Peek reuses the standard, bounded thumbnail request queue only after
  an explicit key press; the library's eight-request cap, one-at-a-time video
  poster extraction, full-video limits and normal scroll scheduling remain.

## Safety and privacy
- All names and descriptions in the compare overlay are inserted as text
  nodes, never untrusted HTML. Media URLs are only from the app's existing
  thumbnail cache. Browser failures degrade to a placeholder.
- No changes to Google OAuth scopes, Drive filenames/content, Manifest,
  Search Index, Sheet approvals, rename/undo, encrypted sign-in or updater.
- These are read-only UI features and cannot implicitly write to Drive or
  Sheets. Full details still uses established per-action consent safeguards.

## Verification
- Fabricated Chromium media fixture tests keyboard quick peek, arrow
  navigation, Escape, focus restoration, two-file selection, disabled
  comparison until ready, no autoplay, and zero remote writes.
- Preserve existing 10k gallery virtualization, thumbnail queues, video
  streaming, mobile viewport and copy-safe media controls.
- Require Linux/Go fuzz/updater/media stress, Windows DPAPI/WebView2 and
  Chromium tests all green before merge or release.
- A separate v2.2.3 publication will revalidate independently and package
  checksummed UI patch, Windows executable and desktop bundle.
