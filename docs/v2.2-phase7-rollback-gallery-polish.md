# v2.2.7: Retire Jump Navigator, Polish Existing Gallery

The v2.2.6 Jump Navigator added another panel to the gallery and was not
wanted. v2.2.7 removes all of its runtime code, DOM, styles, bindings and
dedicated tests. The older release note is retained as a marked historical
record, not as a supported feature.

Instead, this patch provides only small improvements to existing controls:
- Manual Load more moves keyboard focus onto its replacement button, or
  the results landmark after the final batch, without scrolling the page.
- The existing grid/list toggle has a tooltip matching the next action.
- Back to top uses instant scrolling when reduced motion is requested.
- The existing result counter uses tabular numbers and the manual button
  has a visible keyboard focus outline.

Turbo Gallery virtual rendering, deferred video thumbnail loading, desktop
streaming and sign-in, local albums, review workflows, Drive read-only scope
and approval-gated remote editing are deliberately unchanged.

Validation: Chromium e2e checks absent navigator DOM on 2 and 10,000 result
libraries, keyboard Load more batching and focus, layout tooltip and the
existing Turbo Gallery performance, autoplay, Drive/Sheet write-safety suites.
Green Linux and Windows builds remain merge/release prerequisites.
