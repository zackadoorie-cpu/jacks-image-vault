Recovery

If a patch causes problems, restore the previous UI or the built-in v2.0.0 screen. Neither option changes your Drive files or saved connection IDs.

Install Image Vault

In Microsoft Edge or Google Chrome, open the menu and choose Apps → Install this site as an app or Cast, save and share → Install page as app. Some versions also show an Install icon in the address bar.

A web app needs an HTTPS address or localhost. Opening this HTML from a ZIP or file folder will not make it installable. For daily use, publish the app shell to a trusted HTTPS host; keep all personal images in Google Drive.
