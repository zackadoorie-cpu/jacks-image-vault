PRIVACY-FIRST IMAGE COMPARISONS

Similarity Lab

Find possible duplicates across folders without changing a single Drive file. Metadata candidates are not confirmed duplicates.

Possible duplicates in Drive

Read-only: matching filenames and exact file byte sizes identify leads. This does not prove identical images or SHA-256 hashes. No original files are downloaded for this scan.

Fingerprint evidence and coverage

Existing Manifest SHA-256 (column V) and first-frame perceptual hash (column W) are reported separately. Recorded values are historical evidence, not proof that current Drive bytes still match. Perceptual matches are leads, never evidence of identical bytes. No originals are downloaded until you explicitly start a bounded read-only batch.

Compare files you choose

Optional and entirely local. Choose up to 24 JPEG, PNG or WebP files, each no larger than 15 MB, 96 MB total. SHA-256 confirms identical bytes; a 64-bit perceptual dHash identifies visually similar previews, which may be false positives. No filenames, images or hashes are uploaded or saved.

All comparisons are read-only. This feature does not delete, move, rename, upload or modify source photos, spreadsheets or local reviews. Clear local comparison to discard temporary previews and computed fingerprints.

    Set up your launcher in your user Apps folder and create matching Desktop and Start Menu shortcuts. No administrator access or automatic startup.
    
      
    
      
      
    Windows will ask you to confirm before anything is installed.
    
      
    The Windows shortcut launches the local server. For the running window's own taskbar icon, install the browser app below and pin that installed app, not the EXE launcher.
    
    
    
    
    
      
    Recommended: browser app with its own taskbar icon
    
      
    For the running window's own taskbar icon, open http://localhost:8765/ in a normal Microsoft Edge tab while the Vault EXE is running. Use Edge's Apps → Install this site as an app option, then open edge://apps and choose Details → Pin to taskbar.
    
      
    Important: A pinned browser app cannot start the local Vault server by itself. When Vault is fully closed, open its Windows Desktop or Start Menu launcher first. The browser app pin is for the running window's identity.
    
      
      
    The browser may offer an Install icon in the address bar.
